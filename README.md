# 다리야, 가지 마!

늘어나는 두 다리로 케이크를 지켜 배달하는 모바일 세로 화면용 웹 게임입니다.
몸통 골반의 펌프에서 **공용 붉은 동력액**이 두 다리로 흐르는 장난감이 되어,
발판 사이를 건너 손님에게 케이크를 배달하세요.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 바로 열면 됩니다.

- 데스크톱 브라우저: 창이 넓으면 자동으로 휴대폰 크기의 세로 프레임으로 표시됩니다.
  개발자 도구의 기기 모드(예: 390×844)로 열어도 됩니다.
- 휴대폰: 같은 폴더를 아무 정적 서버로 올리거나(`npx serve .`) 파일로 열면 됩니다.
- 외부 네트워크가 필요 없습니다(글꼴은 `css/font.css`에 내장, 소리는 WebAudio로 실시간 합성).
- `index.html?level=3` 처럼 열면 해당 스테이지로 바로 시작합니다.

## 조작 (터치 / 마우스 클릭 동일)

| 입력 | 동작 |
| --- | --- |
| 아래 **왼다리 / 오른다리** 버튼 탭(또는 화면 속 다리 탭) | 그 다리로 동력액 한 칸을 보냄 |
| 장면을 끌기 | 앞쪽 미리 보기(놓으면 돌아옴) |
| 오른쪽 위 ⏸ | 일시정지 · 다시 하기 · 스테이지 선택 · 소리 |
| 키보드(선택) | A/← 왼다리, D/→ 오른다리, R 다시, Esc 일시정지 |

## 장난감 규칙

1. 동력액 10칸을 두 다리와 골반이 나눠 씁니다. 탭할 때마다 한 칸이 그 다리로 흐르고,
   골반이 비어 있으면 **반대쪽 다리에서 빼 와** 그 다리가 줄어듭니다.
2. 바닥에 **디딘 발은 붙어 있어서**, 그 다리가 늘어나면 몸통을 **발의 반대쪽**으로 밀어냅니다.
   버튼 이름 방향으로 걷는 게 아니라, 실제 발과 몸의 위치 관계대로 움직입니다.
3. 몸통 아래 **추**가 앞발을 넘었을 때 그 앞발을 누르면 **갈아타기**:
   뒷다리가 접혀 떨어지고 그 다리의 동력액은 골반으로 돌아갑니다(확보한 긴 버팀 자세를 잃음).
4. 대신 뒷다리를 한 번 더 밀면 **밀며 떼기**: 앞발이 떨어지고 뒷다리 하나로 더 멀리 버팁니다.
   멀리 갈 수 있지만 무게가 크게 쏠려 쟁반이 기울어집니다.
5. **공중 다리**는 지면을 밀 수 없지만, 누르면 점선을 따라 뻗어 고리 위치에 '착' 붙습니다.
   ×숫자는 닿기까지 남은 탭 수입니다. 고리 위치는 지지 다리의 기울기(몸의 자세)를 따라 바뀝니다.
6. 하나뿐인 지지발은 절대 저절로 떨어지지 않습니다. 발이 떨어지는 건 항상 방금 한 탭의 결과이고,
   버튼에 미리 표시됩니다(밀기 / 밀며 떼기 / 갈아타기 / 뻗기 ×n).
7. 추가 발 바깥으로 나가 무게가 쏠리면 몸통과 쟁반이 기울고, 케이크가 오목한 쟁반 위에서 미끄러집니다.
   장식(딸기·초·체리)은 한 박자 늦게 흔들리다 오래 기울면 떨어집니다. 다시 받치면 제자리로 돌아옵니다.
8. 두 발로 배달 매트 위에 서서 쟁반이 안정되면 배달 완료. 남은 장식 수가 별점입니다.

실패하면 원인(어느 다리로 얼마나 쏠렸는지, 몇 도 기울었는지, 천장 크림에 부딪혔는지)을 알려 주고
중간 저장 지점부터 다시 할 수 있습니다.

## 스테이지

1. 첫 배달 — 튜토리얼: 밀기, 갈아타기, 디디기
2. 쿠키 징검다리 — 넓은 틈: 얼마나 기울인 뒤 갈아탈지
3. 웨하스 계단 — 높낮이: 몸 높이를 올렸다 내리기
4. 마카롱 기둥 — 좁은 기둥: 착지 고리를 정확히 맞추기
5. 휘핑 동굴 — 낮은 천장: 다리를 짧게, 보폭은 넓게
6. 생일 파티 — 종합

## 파일 구성

- `index.html`, `css/` — 화면, 스타일, 내장 글꼴(Jua 부분 집합)
- `js/sim.js` — DOM 없는 물리·규칙 시뮬레이션(브라우저와 Node 공용)
- `js/render.js` — 캔버스 렌더링(무대, 장난감, 케이크, 미리보기, 효과)
- `js/audio.js` — WebAudio 절차적 효과음·목소리·음악
- `js/levels.js` — 스테이지 데이터
- `js/main.js` — 게임 루프, 입력, 카메라, HUD·조작 패널, 화면 전환, 힌트
- `tools/` — 개발용 도구
  - `solve.js` 빔 탐색으로 스테이지가 클리어 가능한지 검증: `node tools/solve.js 4 200 0.7`
  - `replay.js` 탭 순서 재생 추적, `film.js` 실제 브라우저로 재생해 콘택트 시트 생성
  - `shot.js` Playwright 스모크 테스트/스크린샷, `audiocheck.js` 효과음 레벨 점검
  - `e2e.js` 실제 브라우저에서 탭 경로로 스테이지를 실시간 플레이, `naive.js` 정해진 리듬만으로 깰 수 있는지 점검
  - `build-font.py` 게임에 쓰인 글자만 담은 글꼴 부분 집합 재생성

모든 스테이지는 `tools/solve.js`로 0.45초/탭과 0.7초/탭 속도 모두에서 장식 3개를 지킨 채
클리어 가능한 것을 확인했습니다.
